# Daily Report Assistant 📊

Приложение для ведения ежедневных отчетов и планирования задач.

## ✨ Возможности

- 📝 Создание и управление задачами на день
- 📄 Формирование ежедневных отчетов
- 📈 Просмотр статистики за неделю
- 🔄 Автоматическая нумерация задач
- 📋 Копирование отчетов в буфер обмена
- 💾 Сохранение планов на завтра
